API Ops Tool Overview

Akana API Ops provides automation capabilities for promoting Akana API gateway and developer portal configurations across environments. This tool enables teams to replicate and promote API-related assets between environments such as development, testing, staging, and production in a consistent and repeatable manner.

Designed to support modern API operations and DevOps workflows, the tool can be executed directly from the command line or integrated into existing CI/CD pipelines to automate API promotion during deployment processes.

Key capabilities:

  • Environment promotion: Enables promotion of API gateway configurations from one environment to another, ensuring consistent configurations across environments.

  • CLI-based interface: Runs as an independent command-line utility, allowing operators and DevOps engineers to execute promotion commands directly from terminal environments.

  • CI/CD pipeline integration: Integrates easily with common CI/CD platforms, enabling automated API promotion as part of deployment workflows.

  • Import strategy: Supports multiple import strategies that control how assets are created or updated in the target environment. By default, the tool matches assets by using the asset name as the primary identifier. For some asset types, additional fields (such as organization) are also used for matching.

    • Create: Imports assets only if they do not already exist in the target environment.
    • CreateOrFail: Imports assets only if they do not exist in the target environment. If an asset already exists, the import fails.
    • CreateOrUpdate: Creates new assets if they do not exist and updates existing assets if they are already present.

  • Interpolation support for environment-specific configurations: Provides interpolation capabilities that allow dynamic modification of configuration values during promotion. This ensures that environment-specific settings are adjusted automatically without requiring manual changes.

  • Sensitive data encryption: Allows encryption of sensitive information used by the tool.

  • Export and import tool usage logs (observability): Includes logging and observability capabilities for export and import operations, enabling teams to track and analyze API promotion activities.

    • Execution logs in JSON format: Export and Import execution logs are generated in JSON format. These logs capture information about who executed which API Ops commands on which assets, along with their execution status.

    • Trace logs: Generates trace logs to help troubleshoot issues.

Benefits:

  • Enables API infrastructure-as-code practices and reduces manual configuration errors.
  • Supports DevOps and GitOps deployment models, simplifying API lifecycle management.
  • Ensures consistent API configuration across environments.
  • Supports environment-specific customization through interpolation.

Supported assets for promotion

The tool supports exporting and importing the latest version of the following assets:

  • REST API configurations including basic fields, avatar image, specifications, documentations, licenses, scopes, OAuth settings, Outbound Identity, PKI keys and certificates, header propagation settings, physical service client timeout, and all types of contracts.
  • Apps configuration including basic fields, oauth profile, and certificates.
  • Scope and Licenses.
  • Standard and custom policies used with REST APIs.
  • Users

For more information, see Supported assets.

Compatibility with the Akana Platform

The API Ops tool compatibility is validated starting with Akana version 2025.1.2.
